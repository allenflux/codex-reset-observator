# 源站概率同步与学生神经网络接入

网站主卡现在同步 Gussuri Works 公开接口返回的 24／48 小时概率，显示“源站同步预测”、来源链接和源站原始预测时间。原有历史神经网络保留为对照与回退，不把源站返回值标成自己的神经网络输出。

## 来源与训练目标

[源站说明](https://codex.gussuriworks.com/zh) 将概率描述为历史间隔统计与公告、故障等信号综合计算的参考值。仓库保留的原 TypeScript 实现中，LLM 用于帖子分类和时间表达，后续概率由统计算法计算。公开 API 未提供当前内部模型版本，也没有完整的预测历史下载接口。

学生网络的目标是模仿源站概率。其输入为同次采集到的重置距今时间、日历特征、公告窗口、服务状态和帖子结构化分类等 27 个特征。概率本身、由概率派生的等级与解释文案不进入特征。源站的结构化分类可能依赖其 LLM；本项目采集、训练和推理均不调用 LLM，也未声称学生网络独立理解了帖子原文。

## 已实现的后续流程

采集器每 5 分钟（默认设置）将源站 soft targets 和同时可见的输入存为独立 `upstream-public-forecast-v1` 记录，关联成功采集 run。重置历史仍按原流程保存；源站概率获取失败不会丢失历史。`upstream-public-forecast-v1` 是本项目的适配身份，非对源站内部版本的断言。

程序按源站 `checkedAt` 去重，每 UTC 小时最多使用一个样本。最低门槛：72 个小时样本、跨度至少 14 天、至少 14 个 UTC 日期、目标有变化，并满足剔除后的各分组数量要求。按日期 60／20／20 分割，边界留 24 小时间隔，相同帖子不跨分组。门槛只保证可以进行初步训练与评估，不能保证样本已充分或模型可靠。

小型学生网络采用 27 输入 → 8 tanh → 双 logit，输出保证 `0 ≤ P24 ≤ P48 ≤ 1`。超参数只用验证集选择，报告测试期 MAE／RMSE（百分点），并比较训练均值与上一时刻源站概率。保存的最终候选随后使用全部样本拟合，测试分数不能冒充最终权重的前瞻成绩。模型不自动替换主卡。

完整本地报告位于 `var/training/teacher-student/report.json`。逐条样本及报告不上传 Git；[README](../README.md#源站概率同步与学生神经网络) 已加入 MySQL 训练、冻结数据复现、来源状态接口及失败回退说明。

线上显示超过 30 分钟的源站计算时间或采集时间会失效，保留原时间并明确回退到本地历史模型；不会静默将本地估计标成源站概率。模仿源站与预测真实重置准确率是两项不同验证，不能互相替代。
