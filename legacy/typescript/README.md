# Archived original implementation

The pre-migration Next.js / TypeScript application, evaluation scripts and Windows
C# monitor are retained here for reference. The main project now runs from the
root Python package; see ../../README.md.

Before archiving, all 1,810 original tests, ESLint, TypeScript checks and the Next.js
production build passed. The archive itself is not an actively maintained deployment.
Some scripts refer to root `docs`, `reports`, `extension`, `supabase` and `.github`
paths; use the original Git revision when reproducing the full old workspace.

The Chrome extension and Supabase SQL migrations remain at repository root.
Advanced A/B/C model experiments and former LLM workflows in this archive are not
part of the Python runtime.
